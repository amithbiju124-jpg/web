# CSE Department Website

A simple, multi-page college department website built with plain HTML and CSS.
Created for the assignment *Design and document a website for a college department using HTML*.

**Student:** Amith Biju | **Roll No:** 33 | **Register No:** FIT23CS033 | **Class:** S7 CSE A

## Pages

| File | Content |
|------|---------|
| `index.html` | About the department, vision and mission, news |
| `faculty.html` | Faculty table (name, designation, specialization) |
| `programmes.html` | Programmes and list of subjects offered |
| `facilities.html` | Labs and other facilities with an image |
| `contact.html` | Address and student enquiry form |

## Run locally

Open `index.html` in any web browser. No build step or server is needed.

```
department-website/
```
